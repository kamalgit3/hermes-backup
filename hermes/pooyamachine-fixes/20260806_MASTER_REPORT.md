## 🔧 تعمیرات اصلی انجام‌شده

### ۱. رفع لینک‌های http → https (۵ لایه کامل)

| لایه | محل | تعداد |
|---|---|---|
| ۱ | محتوای صفحات (post_content) | ~۳۱ |
| ۲ | تنظیمات قالب (codevz_theme_options) | ۷ فیلد |
| ۳ | داده المنتور (_elementor_data) | ~۵۸ |
| ۴ | ریوولوشن اسلایدر (جدول‌های v6+v7) | ~۱۲ ردیف |
| ۵ | **فایل‌های CSS گوگل‌فونت Elementor** (roboto.css + robotoslab.css) | **۲۲۵** |

**نکته مهم لایه ۵:** این لایه در HTML صفحه دیده نمی‌شد (فایل CSS جداگانه روی دیسک است) و فقط با تست مرورگر واقعی (Playwright — خطاهای Mixed Content کنسول) قابل کشف بود. بعد از فیکس: **۰ خطای Mixed Content، ۰ درخواست http**.

### ۲. رفع منوی موبایل (مهم‌ترین تعمیر)

**ریشه مشکل:** قالب Xtra شخصی‌سازی شده بود و کد `theme-functions.php` فقط وقتی `elementor-preview` در URL بود `wp_footer()` را صدا می‌زد:
```php
$is_elementor = (isset($_GET['elementor-preview']) && $_GET['elementor-preview']);
if ($is_elementor) { wp_footer(); }
```
نتیجه: هیچ اسکریپت قالب (منوی موبایل، sticky، mobile-nav) لود نمی‌شد و حتی تگ `</body>` وجود نداشت.

**راه‌حل (بدون دست زدن به فایل قالب):** اسنیپت دائمی `kp-footer-fix` — خروجی را بافر می‌کند و در shutdown اگر `wp_footer()` اجرا نشده بود، اجرایش می‌کند.

**مشکلات ثانویه و راه‌حل‌ها:**
- همبرگر منو با CSS مخفی بود → اسنیپت `kp-mobile-menu-css`
- پنل آف‌کانواس باز می‌شد ولی نمایش داده نمی‌شد → اسنیپت `kp-offcanvas-css`
- **تأیید نهایی:** تست Playwright — منو باز/بسته می‌شود، ۲۳ آیتم، بدون خطای JS

## ⚠️ درس‌های فنی ثبت‌شده (برای جلسات آینده)

1. **اسنیپت Code Snippets = PHP خالص** — بدون تگ `<?php ?>` (تگ‌گذاری باعث بی‌صدا رندر نشدن می‌شود)
2. **راستی‌آزمایی با curl**، نه urllib (پروکسی کانتینر هدرها را حذف می‌کند)
3. **جستجوی http در همه لایه‌ها**: post_content، theme options، `_elementor_data` (JSON-escaped: `http:\/\/`)، revslider (دو جدول v6+v7)، فایل‌های CSS روی دیسک
4. **قبل از ساختن روی یک هوک، ثابت کن اجرا می‌شود** (مارکر تست) — wp_footer در این سایت هرگز اجرا نمی‌شد!
5. **REST لیست ممکن است کش باشد** — حذف با 500 یعنی قبلاً حذف شده (لیست دروغ می‌گوید)؛ اثبات با 404 روت یا خواندن مستقیم دیتابیس
6. **تست UI با مرورگر واقعی (Playwright)** — curl HTML استاتیک می‌بیند، نمی‌تواند کلیک کند یا خطاهای کنسول را ببیند
7. **بکاپ قبل از هر تغییر** + purge_all بعد از هر تغییر + راستی‌آزمایی با `?nocache=`
