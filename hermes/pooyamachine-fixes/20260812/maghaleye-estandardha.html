استانداردهای صنعت ماشینسازی و لولهکشی — مروری بر ASME، ASTM و API

در صنایع نفت، گاز، پتروشیمی و نیروگاهی، طراحی و ساخت بدون مراجعه به کدها و استانداردهای معتبر ممکن نیست. این مقاله با تکیه بر مجموعه آموزشی «آشنایی با استانداردهای ASME، ASTM و API» ساختار هر سه خانواده استاندارد را بررسی میکند: از مفاهیم پایه لوله و اتصالات (قطر اسمی NPS و شماره ضخامت SCH) تا تقسیمبندی بخشهای ASME، ساختار ۱۵ بخشی ASTM و استانداردهای کاربردی API برای خطوط لوله، مخازن و شیرآلات.

تفاوت کد و استاندارد

کد معمولاً شامل الزامات لازم برای طراحی، انتخاب متریال، ساخت، نصب، آزمایش و بازرسی است و باید بدون تفسیر و با در نظر گرفتن تلورانسها اعمال شود. استاندارد اما در مجموعه خود نیاز به محاسبات اضافی و تفسیر دارد و دامنه استفاده از آن قابل بسط است. در یک پروژه واقعی، مهندس باید این دو را از هم جدا نگه دارد.

لوله و اتصالات؛ الفبای لولهکشی صنعتی

لوله قطعهای استوانهای توخالی با طول، قطر و ضخامت مشخص است که برای انتقال سیال ساخته میشود. مشخصات اصلی آن چهار پارامتر است: قطر خارجی (OD)، قطر داخلی (ID)، ضخامت دیواره و طول. طولهای اولیه ساخت لوله معمولاً ۶، ۱۲ و ۲۴ متر است.

قطر اسمی (NPS): عددهای قید شده در جدول استاندارد، قطر اسمی لوله هستند و قطر خارجی و داخلی تا حدودی با این عدد متفاوت است. نمونه: لولهای با قطر اسمی ۶ اینچ، قطر خارجی ۱۶۸ میلیمتر دارد. این اختلاف میان عدد اسمی و واقعی، منبع خطای رایج میان تازهکارهاست.

شماره ضخامت (SCH): برای هر لوله با قطر مشخص ممکن است تا ۱۲ نوع ضخامت وجود داشته باشد که با شماره SCH مشخص میشوند؛ از SCH 10 تا 160 به همراه شناسههای STD (معادل ۴۰)، XS (معادل ۸۰) و XXS. نمونه: ضخامت لوله ۶ اینچ با SCH 40 برابر ۷.۱۱ میلیمتر است. جدول کامل این اعداد در ASME B36.10 آمده است.

لولهها به دو روش ساخته میشوند: درزدار (Welded) و بدون درز (SMLS). مجموعه زانو، سهراهی، کاهنده و فلنج را اتصالات یا Fitting مینامند.

ASME؛ انجمن مهندسین مکانیک آمریکا

ASME از سال ۱۹۱۱ در زمینه لوله، ظروف تحت فشار و اتصالات فعالیت دارد و بخشهای I تا XI را شامل میشود. در صنایع نفت، گاز و پتروشیمی کاربرد اصلی به بخشهای II (متریال)، V (آزمونهای غیرمخرب)، VIII (ظروف تحت فشار) و IX (جوشکاری) برمیگردد.

شمارهموضوع
ASME IIمشخصات متریال (Part A: فلزات آهنی، Part B: غیر آهنی، Part C: الکترود و فیلر، Part D: خواص فیزیکی)
ASME Vآزمونهای غیرمخرب (NDT)
ASME VIIIظروف تحت فشار (Div 1، Div 2، Div 3)
ASME IXتأیید صلاحیت جوشکاری (فصلهای QW)
ASME B31کد لولهکشی (B31.1 نیروگاهی، B31.3 فرآیندی، B31.4 انتقال مایعات، B31.8 گاز)
ASME B16ابعاد اتصالات (B16.5 فلنج، B16.9 اتصالات جوشی، B16.11 سوکت جوش و رزوهای، B16.47 فلنج بزرگ)

نامگذاری متریال: فلزات آهنی طبق الگوی SA-XYZ نامگذاری میشوند؛ مثلاً SA-106 (لوله بدون درز)، SA-105 (فلنج و اتصالات) و SA-234 (اتصالاتی مانند زانو، سهراهی و کاهنده). فلزات غیر آهنی با الگوی SB-XYZ نامگذاری میشوند؛ SB-209 برای آلومینیوم و SB-464 برای آلیاژهای پایه نیکل.

آزمونهای غیرمخرب (ASME V): پنج روش اصلی NDT: بازرسی چشمی (VT)، آزمون با امواج صوتی (UT)، ذرات مغناطیسی (MT)، مایع نفوذگر (PT) و پرتونگاری (RT). هر کدام برای کشف دسته خاصی از عیوب به کار میرود.

ASTM؛ انجمن آزمایش و مواد

ASTM روشهای آزمون، انواع متریال و سیستمهای تولید را توضیح میدهد و شامل دستورالعملهای کامل برای اندازهگیری ترکیب شیمیایی فلزات و انجام آزمونهای مخرب مانند کشش، ضربه و خمش است. این مجموعه ۶۷ جلد دارد که در ۱۵ بخش سازماندهی شدهاند.

  • بخش اول: محصولات آهن و فولاد (۶ جلد — لوله و تیوب، فلزات ریختهگری، ورق و تسمه، سازهها و ظروف تحت فشار)
  • بخش دوم: محصولات فلزی غیر آهنی (مس، آلومینیوم، نیکل و...)
  • بخش سوم: روشهای آزمون و دستورالعملهای تحلیل
  • بخشهای چهارم تا پانزدهم: سیمان و بتن، پتروشیمی و روانکارها، پلاستیک و لاستیک، انرژی و تجهیزات پزشکی و...

ارتباط ASTM و ASME مستقیم است: نام یک فلز طبق ASTM به شکل A-XYZ نوشته میشود (مثل A-193) و از نظر خواص و آنالیز شیمیایی با SA-193 طبق ASME II Part A تفاوتی ندارد؛ با این تفاوت که ASTM گستردگی بیشتری دارد.

API؛ انجمن نفت آمریکا

API در زمینه لولهکشی، مخازن، اتصالات و شیرآلات استانداردهای تخصصی دارد و به چهار گروه Spec، Std، RP و Bulletin تقسیم میشود.

  • API 5L — استاندارد ساخت و متریال لولههای فولاد کربنی خطوط انتقال؛ API 1104 — جوشکاری خطوط لوله
  • API 620 و API 650 — طراحی، ساخت و بازرسی مخازن ذخیره؛ API 653 — تعمیر و بازرسی دورهای مخازن
  • API 6D — استاندارد ساخت شیرآلات؛ API 6FA و API 607 — آزمونهای Fire Safe؛ API 6A — تجهیزات سرچاهی
  • API 570 — بازرسی لولهکشی؛ API 510 — بازرسی ظروف تحت فشار

جمعبندی

سه خانواده ASME، ASTM و API در کنار هم چرخه کامل یک پروژه صنعتی را پوشش میدهند: ASTM متریال و روش آزمون را تعریف میکند، ASME الزامهای طراحی، ساخت و بازرسی و کدهای لولهکشی را مشخص میکند، و API برای موارد ویژه صنعت نفت استاندارد تخصصی ارائه میدهد. شناخت مرز هر کدام و تفاوت کد با استاندارد، نخستین گام برای فعالان حوزه طراحی، ساخت، نصب و نگهداری تجهیزات صنعتی است.

نیاز به تجهیزات فرآوری پودر مطابق استاندارد دارید؟ پویا ماشین البرز میکسر پودر، نوار نقاله و تجهیزات انتقال مواد را با استانداردهای صنعتی میسازد: مشاوره فنی در واتساپ — مشاهده محصولات
